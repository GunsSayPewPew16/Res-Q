A profiled donor list, a profiled recipient list, and a route between them: the forecast estimates what a kitchen has spare today, the matcher finds the shelter nearest that needs it, the order binds both sides.

def shared_categories(mine, theirs):
    return list(set(mine) & set(theirs))

def rank(candidates, me):
    scored = [(haversine_km(me, c), c)
              for c in candidates
              if shared_categories(me, c)]
    scored.sort()
    return [c for _, c in scored]
